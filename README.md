## Deskripsi
Tugas ini merupakan pembuatan website sederhana yang membahas hobi menggunakan HTML dan CSS. Website terdiri dari tiga halaman yang saling terhubung untuk menampilkan informasi mengenai hobi.

## Struktur File
- `index.html` — Halaman utama website.
- `halaman2.html` — Halaman kedua yang berisi informasi tentang hobi.
- `halaman3.html` — Halaman ketiga yang berisi informasi tambahan mengenai hobi.
- `style.css` — File CSS untuk mengatur tampilan website.

## Fitur Website
1. Memiliki tiga halaman website.
2. Menampilkan informasi mengenai hobi.
3. Menyediakan navigasi untuk berpindah halaman.
4. Menggunakan CSS eksternal untuk mengatur tampilan.
5. Memiliki desain sederhana dan mudah dibaca.

## Teknologi yang Digunakan
- HTML5
- CSS3
